知识库说明

如何使用和维护你的技术知识库

📚 添加知识库文件

  1. 将 Markdown 文件（.md）放入 data/knowledge_base/ 目录
  2. 文件会自动按照 #、##、### 标题进行分段
  3. 每个分块约 1000 字，块间有 200 字重叠以保证语义完整
  4. 点击"索引管理 → 重建索引"使新文件生效

🔧 系统架构

  • Embedding 模型：硅基 Qwen/Qwen3-Embedding-4B
  • LLM 模型：百炼 qwen3.7-max-2026-05-20
  • 向量存储：FAISS IndexFlatIP（内积搜索）
  • 分块策略：按标题分段 → 按段落切块 → 超长滑窗
