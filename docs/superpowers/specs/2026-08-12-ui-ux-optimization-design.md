# UI/UX 优化设计文档

## 概述

对 RAG 面试助手进行界面重构，解决配色缺乏科技感、布局空间利用率低、交互细节缺失三个核心问题。

## 配色方案

### CSS 变量变更

| 变量 | 当前值 | 目标值 | 用途 |
|------|--------|--------|------|
| `--accent` | `#d4a95a` | `#6054F1` | 主色调 |
| `--accent-hover` | `#e8be6d` | `#7B6FF2` | hover 状态 |
| `--accent-glow` | `rgba(212,169,90,0.15)` | `rgba(96,84,241,0.15)` | 发光/阴影 |

### 受影响的 DOM 元素

所有引用 `var(--accent)`、`var(--accent-hover)`、`var(--accent-glow)` 的位置同步更新，包括：

- brand icon 渐变背景（`linear-gradient(135deg, var(--accent) 0%, #b8944f 100%)` → 蓝紫色渐变）
- nav-item.active 背景色与文字色
- 发送按钮背景色
- 输入框聚焦边框和阴影
- 进度条填充渐变
- session-item.active 背景色
- 流式光标颜色
- 来源文件链接颜色
- 会话指示器圆点
- 用户头像渐变
- 搜索高亮：改为 `rgba(96,84,241,0.25)` 背景，白色文字 `#ffffff`
- 按钮 hover 边框色

## 布局重构

### 侧边栏结构

从 260px 缩窄到 200px，内部模块重新排列：

```
┌─────────────────┐ 200px
│ Brand (紧凑)     │  ~48px
│ 导航 (2项)       │  ~60px
│ 会话列表 (弹性)  │  ← 剩余高度，overflow-y: auto
│ ─────────────── │
│ 系统状态 (一行)  │  ~20px
│ 底部 (登录/版本) │  ~36px
└─────────────────┘
```

### 导航项变更

从 3 项减为 2 项：

1. **问答** — 聊天界面，默认视图
2. **设置** — 合并当前"索引管理"和"知识库"视图

### 设置视图内容

合并后的设置视图包含：

- **索引状态卡片**：显示当前索引状态（已构建/未构建）、文本块数、文件数
- **索引操作**：构建/重建索引按钮 + 进度条
- **知识库文件管理**：上传区域（拖拽/点击上传）+ 文件列表（显示文件名、大小、类型、修改时间）+ 删除按钮
- **文件上传限制**：.md/.pdf/.docx，单个文件最大 50MB

### 会话列表

移除 `max-height: 240px` 限制，改为 `flex: 1` + `overflow-y: auto`，占满侧边栏剩余高度。

### 系统状态

从 3 行独立组件改为一行紧凑文字，放在侧边栏底部、分隔线之上：

```
● 向量索引 ✓  ● Embedding ✓  ● LLM ✓
```

## 交互细节

### 导航 Bug 修复

`switchSession(sessionId)` 末尾增加：

```javascript
if (state.currentView !== 'chat') {
    switchView('chat');
}
```

确保无论用户在哪个视图，点击会话都自动跳转到问答页。

### Markdown 渲染验证

确认所有 AI 消息渲染路径都使用 `renderMarkdown()` 或 `renderMarkdownNoHighlight()` 函数，而非 `textContent` 赋值。

### AI 回答操作按钮

每个 AI 回答底部添加操作按钮行，包含：

1. **复制答案**：`navigator.clipboard.writeText()` 复制纯文本，显示 Toast
2. **重新生成**：取当前问题的原文，重新调用 `/api/query/stream`，替换当前 AI 回答内容
3. **展开/收起来源**：参考来源列表默认折叠，点击按钮展开/收起

## 实施优先级

1. 配色迁移（CSS 变量替换，纯样式变更，不影响逻辑）
2. 布局重构（HTML 结构调整 + CSS 布局变更）
3. 交互细节（JS 逻辑变更 + 新增操作按钮 DOM）

## 涉及文件

- `frontend/css/style.css` — 配色变量、布局尺寸、状态栏样式
- `frontend/index.html` — 导航项、侧边栏结构、设置视图
- `frontend/js/app.js` — switchSession、switchView、操作按钮逻辑
